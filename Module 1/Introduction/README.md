# RTL Design & Simulation – Introduction

In this session, I learned the fundamentals of **RTL design, simulation, and testbench development**, forming the foundation for my VLSI learning journey.

### Key Concepts
- **Design:** The actual hardware logic (DUT) that implements the required functionality.
- **Simulation:** The process of testing and analyzing the behavior of the design using software before hardware implementation.
- **Test Bench:** A verification environment that generates inputs (stimulus) for the DUT and observes its outputs.


### Learning Outcomes
- Understood the difference between **Design, Simulation, and Test Bench**.
- Learned the basic **Icarus Verilog simulation flow**.
- Gained a foundation for **Verilog RTL design and verification**.
